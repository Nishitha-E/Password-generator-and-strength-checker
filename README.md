🔐 Password Generator & Strength Checker

A fully responsive and modern Password Generator built using HTML, CSS, and JavaScript.
This app generates strong passwords, checks password strength in real-time, and maintains a recent password history for convenience.

🚀 Features
🔑 Password Generator

Adjustable password length (4–50)

Toggle options for:

Uppercase A–Z

Lowercase a–z

Numbers 0–9

Special symbols (!@#$%^&*)

Automatically generates a password on page load

📊 Strength Checker

The strength meter evaluates:

Length criteria

Variety of character types

Displays:

Strength bar (Weak / Fair / Good / Strong)

Score out of 7

Color-coded visualization

📜 Password History

Stores last 5 generated passwords

Quick "Copy" button for each historical password

📋 Copy to Clipboard

One-click copy

Temporary “Copied!” feedback
